## About Me

I'm a mobile application developer building production-ready iOS and Android apps with Flutter. I've been shipping software since **2021**, across client projects and real-world products, taking them from idea to release.

Flutter is my main tool, but I'm comfortable going native with **Swift** and **Kotlin**, and I work across the backend when the product needs it. ## How I Work

For non-trivial Flutter apps I keep business logic separate from the UI and choose an architecture that stays easy to test and change over time.

```
Clean Architecture  →  BLoC / fitting state management  →  TDD  →  CI/CD  →  Production monitoring
```

I use AI development tools every day for research, planning, refactoring, testing, debugging, and repetitive implementation work. They don't replace engineering judgment; they free up more time for the product problems that matter.
