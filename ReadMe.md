Clean Architecture → BLoC / appropriate state management → TDD → CI/CD → Production monitoring

I also use AI-powered development tools as part of my daily workflow — for research, planning, refactoring, testing, debugging, and speeding up repetitive implementation work.

The goal isn't to replace engineering judgment. It's to spend more time solving product problems and less time on repetitive work.
